# FreeThinker Product Overview

FreeThinker is a free AI agent that automates tasks using natural language commands. It leverages open-source LLM APIs (no cost per token) to provide intelligent task automation without requiring paid API keys.

## Key Features
- Zero-cost operation using free open-source model APIs
- Multiple LLM support (Llama 3.1 70B, Mistral Nemo Instruct)
- Natural language task automation
- Extensible tool system for various operations
- Interactive command-line interface

## Core Functionality
The agent uses a two-stage reasoning process:
1. **Tool Selection**: Determines the most appropriate tool for a given query
2. **Tool Execution**: Formats inputs and executes the selected tool

## Available Tools
- Basic Calculator: Mathematical operations
- Weather Forecaster: Location-based weather information
- Reddit Scraper: Subreddit content extraction
- Search Tool: Google search functionality
- Web Scraper: Webpage content extraction

## Target Users
Developers and users who want AI task automation without API costs, suitable for experimentation and learning about AI agents.
